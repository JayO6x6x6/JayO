# BioWave | Sonic Health Lab

Interactive browser prototype for cancer-research visualization, bioelectricity hypothesis exploration, cymatic simulation, signal synthesis and evidence mapping.

## Run

Open `index.html` in a browser, or publish the `biowave/` directory with GitHub Pages.

## Modules

- Research Hub
- Cancer Explorer — synthetic membrane-potential/state controls
- Cymatic Viewer — mathematical wave-interference field
- Sonic Lab — local browser audio synthesis
- Scan & Compare — local CSV signal summaries
- Evidence Map — links to public research resources
- Research Guardrails

## Scientific boundary

This is a research/education prototype. It does **not** diagnose, treat, cure, prevent, or recommend treatment for cancer. Synthetic visualizations are not measurements of tumors, cells, patients, or therapeutic response. Any experimental biological work requires qualified investigators, appropriate controls, validated instrumentation, biosafety/ethics oversight, and reproducible protocols.
